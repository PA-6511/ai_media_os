# START-LS LS-NEW-2 Simple X Post Template

## Purpose

新刊コミックのX投稿は、作品解説ではなく配信開始・購入導線の簡易告知として扱う。

## Standard Template

```text
配信開始です
#PR #Amazonmanga #Kindle #作者名
『タイトル』第○巻

URL
```

## Rules

- 280文字以内にする。
- アフィリエイトURLを含む場合は `#PR` を必須にする。
- 作品あらすじは入れない。
- 公式説明文・商品説明文・レビュー文を転載しない。
- 価格比較・ポイント還元率比較はX本文では必須にしない。
- 詳細比較はWordPress記事側に寄せる。
- X投稿はこのフェーズでは実行しない。
